Manual do Sistema

Visão Geral

Este sistema foi desenvolvido para auxiliar na gestão de inventário, registro de trocas e agendamento de ativos de TI.

Dashboard

A tela inicial exibe KPIs importantes, gráficos de trocas por setor, feed de atividades recentes e próximos agendamentos. Os cards podem ser arrastados e soltos para personalizar a ordem.

Troca Desktop

Busque um ativo pela Placa Voke ou Serial Voke. Se o ativo for encontrado, você pode registrar uma troca ou enviá-lo para a fila de agendamento. Se não for encontrado, pode ser adicionado manualmente.

Trocar Monitor

Similar à troca de desktops, mas focado em monitores. Busque pelo serial do monitor antigo, informe o novo e o usuário/setor.

Relatórios

Visualize o histórico de trocas de computadores e monitores. Filtre por data, pesquise por termos e alterne entre visualização em tabela ou grade. É possível exportar a lista filtrada ou o relatório completo.

Configurações

Gerencie a interface (tema, layout da sidebar), configure o dashboard (visibilidade e tamanho dos cards) e gerencie os dados (carregar planilhas, sincronizar relatório, limpar dados).

Atalhos de Teclado

Use Ctrl + 1 para Dashboard, Ctrl + 2 para Troca Desktop, Ctrl + 3 para Trocar Monitor, Ctrl + 4 para Relatórios e Ctrl + 5 para Configurações.
